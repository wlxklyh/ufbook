## 关于 GDC

**Game Developers Conference (GDC)** 是全球最大的游戏开发者会议，每年在旧金山举办。会议涵盖游戏设计、编程、美术、音频等多个领域的前沿技术分享。

Epic Games 每年都会在 GDC 上分享虚幻引擎的最新进展和技术实践。
